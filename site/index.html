Free firmware for the Xteink X4 Pro

Your books and your Obsidian vaults, on paper-like ink.

VaultInk turns the Xteink X4 Pro e-reader into a reader for books, comics and your Obsidian notes. Read notes like book pages, follow their links, search every vault, edit a line, and keep them in sync over Wi-Fi.

Install

Install it from this page

No tools to download. Chrome or Edge on a computer talks to the reader over USB and writes the firmware. It takes about a minute.

Early build. Tested by one tester on one X4 Pro so far, so things can still go wrong. Back up your SD card first, and only install it if you're comfortable flashing your reader back to the official firmware if something goes wrong.
This browser can't install VaultInk. Installing needs Web Serial, which only desktop Chrome, Edge and other Chromium-based browsers (Brave, Opera, Vivaldi) have. Firefox, Safari and phone browsers don't. Please open this page in one of those on a computer.

  1. Back up your SD card

    Installing doesn't touch the card, but if anything goes wrong you'll want a copy of your books and notes.

  2. Put the update file on the SD card (for later)

    From the latest release, download vaultink-<version>-x4pro.bin (the file without "factory" in its name) and copy it to the root of the SD card. With it there, you can reinstall VaultInk from the reader itself under Settings → System → SD Card Firmware Update. Don't use the factory file for that; it is only for this page.

  3. Put the X4 Pro into boot mode

    With the reader switched off, press and hold Power, then also press and hold both page-turn buttons, and keep holding them.

  4. Connect it to your computer

    Use a USB-C data cable (some cables only charge). Use Chrome, Edge or another browser with Web Serial, on a computer, not a phone.

  5. Press Install VaultInk

    Choose the device in the list. The installer offers to erase the device first. Erasing wipes everything stored on the reader itself (settings, Wi-Fi networks, the current firmware) but not the SD card. It takes about a minute; wait until it says it's done, then restart the reader with Power.

Your browser can't flash devices. Please use Chrome or Edge on a computer. Flashing needs a secure (https) page.

VaultInk doesn't run on the X4 or X3 yet. They use a smaller chip (ESP32-C3) with less memory, and VaultInk is built for the X4 Pro only for now. The installer would refuse the device anyway.

For these readers, use CrossPoint Reader, the firmware VaultInk is based on.

VaultInk only supports the Xteink X4 Pro for now. The model name is on the box and on the back of the reader. If you have an X4 or X3, pick it above.

Not working?

  • The device isn't in the list. Try another cable (some only charge) or another USB port, and check the reader is still in boot mode (step 3).
  • It connects but won't flash. Try another USB port or browser first. Some units sold by third-party shops have USB flashing locked at the factory. CrossPoint's site has an Xteink unlocker; read its warnings first, since it only supports CrossPoint and CrossInk officially.
  • Going back. Install the official Xteink firmware the same way you installed this one.

Updating later

Once VaultInk is on the device you don't need this page again. Connect the reader to Wi-Fi and open Settings → System → Check for Updates: it finds the newest release, downloads it and installs it. Without Wi-Fi, copy the new vaultink-<version>-x4pro.bin to the SD card and use Settings → System → SD Card Firmware Update.

What it does

A reader for books, and for your notes

Everything CrossPoint Reader does for books stays. VaultInk adds your Obsidian vaults, read straight from the SD card.

  • Canvas files: pan, zoom, tap a card to open its note.
  • Backlinks and recent notes for every vault.
  • Quick settings on a swipe down: light, warmth, night mode, refresh, sleep.
  • Greek and English on-screen keyboard, switched with the globe key.
  • Import a vault from a ZIP over the device's web page.
  • Updates over Wi-Fi from the device itself.

Comics and manga

Comics, cut to fit the screen

Comics go through Banana Comic Converter, a free tool by u/curseofthebanana that runs in the browser on a phone or a computer. Instead of shrinking a whole page, it cuts every page into its panels and repacks them to fill the small screen. It has an X4 / X4 Pro preset, manga (right-to-left) or western order, a panel editor for the pages it gets wrong, and batch conversion.

How it works

Convert to XTCH (or XTC for the fastest page turns), upload the file with the companion app or the device's web page, and read it like a book. Plain CBZ files open too. On the reader, Settings → Library → Convert comics shows a QR code that opens the converter on your phone.

Android companion app

Your phone, talking to the reader

The companion app connects to the reader over Wi-Fi while File Transfer is open. Write a quick note or share text and pictures from any app straight into a vault; browse the whole SD card to upload, download, rename, move and delete; convert comics; and change the device settings from the phone.

Get it

It's released separately, as an APK on the companion releases. Download it on the phone and open it. It needs VaultInk 0.29.0 or newer on the device.

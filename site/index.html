VaultInk

Books and Obsidian vaults on the Xteink X4 Pro.

Test build. This version hasn't been tested on real hardware yet. Back up your SD card first, and only install it if you're comfortable flashing your reader back to the official firmware if something goes wrong.

Install

  1. Use Chrome, Edge or another browser with Web Serial, on a computer (not a phone).
  2. Connect the X4 Pro with a USB-C data cable and turn it on.
  3. Press Install VaultInk, choose the device in the list, and wait until it says it's done. It takes about a minute.
Your browser can't flash devices. Please use Chrome or Edge on a computer. Flashing needs a secure (https) page.

Not working?

  • The device isn't in the list. Try another cable (some only charge), another USB port, and make sure the reader is on.
  • It connects but won't flash. Some units sold by third-party shops have USB flashing locked at the factory. They have to be unlocked with Xteink's tool before any custom firmware can be installed.
  • Going back. Install the official Xteink firmware the same way you installed this one.

Updating later

Once VaultInk is on the device, it checks for new versions itself under Settings → System → Check for Updates.

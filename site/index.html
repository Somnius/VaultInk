Free firmware for the Xteink X4 Pro

Your books and your Obsidian vaults, on paper-like ink.

VaultInk turns the Xteink X4 Pro e-reader into a reader for books, comics and your Obsidian notes. Read notes like book pages, follow their links, search every vault, edit a line, and keep them in sync over Wi-Fi.

Install from your browser Read the docs

Open source: my own code is MIT, the firmware binaries are GPL-3.0-or-later. Built on CrossPoint Reader. Not affiliated with Obsidian, Xteink or CrossPoint.

Install

Install it from this page

No tools to download. Chrome or Edge on a computer talks to the reader over USB and writes the firmware. It takes about a minute.

Early build. Tested by one tester on one X4 Pro so far, so things can still go wrong. Back up your SD card first, and only install it if you're comfortable flashing your reader back to the official firmware if something goes wrong.
This browser can't install VaultInk. Installing needs Web Serial, which only desktop Chrome, Edge and other Chromium-based browsers (Brave, Opera, Vivaldi) have. Firefox, Safari and phone browsers don't. Please open this page in one of those on a computer.

  1. Back up your SD card

    Installing doesn't touch the card, but if anything goes wrong you'll want a copy of your books and notes.

  2. Put the update file on the SD card (for later)

    From the latest release, download vaultink-<version>-x4pro.bin (the file without "factory" in its name) and copy it to the root of the SD card. With it there, you can reinstall VaultInk from the reader itself under Settings → System → SD Card Firmware Update. Don't use the factory file for that; it is only for this page.

  3. Put the X4 Pro into boot mode

    With the reader switched off, press and hold Power, then also press and hold both page-turn buttons, and keep holding them.

  4. Connect it to your computer

    Use a USB-C data cable (some cables only charge). Use Chrome, Edge or another browser with Web Serial, on a computer, not a phone.

  5. Press Install VaultInk

    Choose the device in the list. The installer offers to erase the device first. Erasing wipes everything stored on the reader itself (settings, Wi-Fi networks, the current firmware) but not the SD card. It takes about a minute; wait until it says it's done, then restart the reader with Power.

Your browser can't flash devices. Please use Chrome or Edge on a computer. Flashing needs a secure (https) page.

VaultInk doesn't run on the X4 or X3 yet. They use a smaller chip (ESP32-C3) with less memory, and VaultInk is built for the X4 Pro only for now. The installer would refuse the device anyway.

For these readers, use CrossPoint Reader, the firmware VaultInk is based on.

VaultInk only supports the Xteink X4 Pro for now. The model name is on the box and on the back of the reader. If you have an X4 or X3, pick it above.

Not working?

  • The device isn't in the list. Try another cable (some only charge) or another USB port, and check the reader is still in boot mode (step 3).
  • It connects but won't flash. Try another USB port or browser first. Some units sold by third-party shops have USB flashing locked at the factory. CrossPoint's site has an Xteink unlocker; read its warnings first, since it only supports CrossPoint and CrossInk officially.
  • Going back. Install the official Xteink firmware the same way you installed this one.

Back up and restore

The backup page copies everything in the reader's own memory (all 16 MB, the current firmware included) into a file on your computer, and can write such a file back. Make the backup before you install. Nothing is uploaded. Experimental: not tested on a real reader yet.

Updating later

Once VaultInk is on the device you don't need this page again. Connect the reader to Wi-Fi and open Settings → System → Check for Updates: it finds the newest release, downloads it and installs it. Without Wi-Fi, copy the new vaultink-<version>-x4pro.bin to the SD card and use Settings → System → SD Card Firmware Update.

Prefer a file?

Every version is on the releases page, with notes on what changed and what was tested. The README and docs cover the rest.

Help us debug

Developer build (read-only debugging)

Only if you want to help find a bug. Most people don't need this.

Show the developer build
For helping debug. It is the same firmware plus a read-only serial link: over the USB cable it answers a status request and prints its log, so the debug page can make a report. It can’t read or write your files or settings, press keys or flash anything. It can reboot the reader, change the log level, take a screenshot and write a small bench log to the card. Installing it replaces your current firmware. Update back with the normal button above, or from the reader under Settings → System → Check for Updates when the next release is out.

Anyone who has the reader and a cable can read that status and log and take a screenshot of what is on the screen, so keep the normal firmware on a reader that leaves your hands. The log can hold the names of books, notes and Wi-Fi networks; the debug page guide and docs/devlink.md say what the link can and cannot do.

The developer build is not published for this version yet.

What it does

A reader for books, and for your notes

Everything CrossPoint Reader does for books stays. VaultInk adds your Obsidian vaults, read straight from the SD card.

Books and the Library

  • Reading presets: ten named sets of your Text settings, applied with one press from the book menu. A long press on the house at the top sleeps the device.
  • Browse Files has a sort gear (name, date, size) and bigger icons with the file type inside; favourite books get a star, and a Wi-Fi and a Bluetooth mark show in the top strip when the radio is on.
  • Go to page in the book menu under More: a slider over the page numbers of the status bar's bracket number. The home screen has equal tiles, and Books counts books only.
  • MOBI, PRC, AZW and AZW3 books open (Huffman compression too); books with DRM are refused. Text, bold, italic, headings, lists, tables and pictures show; chapters and links don't yet. Opened on a real X4 Pro.
  • PDFs open as reflowing text, Greek and form fields included, up to four columns, with headings, bold and italic when Style is on. No pictures, tables or scans.
  • Settings > Reader > Book menu options: reorder the book menu’s More and Text panels and hide the entries you don’t use.
  • CBZ comics straight from the card: chapters from folders, covers, landscape spreads as two pages, manga right to left, a page cache for faster turns. XTC and XTCH from the Banana Comic Converter, with a QR code in Settings that opens the converter on your phone.
  • Random page!: a random page of a random book, saving nothing, with a way back.
  • Book info on a long press, Favourites, Authors as folders, and All | Books only to hide the notes.
  • A book's highlights written to a note in your vault, sent on by LiveSync.
  • Reading stats on the sleep screen: today, week, month and total, your last three books, a calendar, streaks and finished books.

Notes and vaults

  • Flashcards from your notes: tag a note, write Front::Back, review with spaced repetition. Nothing is written into your notes.
  • Renaming a note updates the links to it. Deleted notes go to .trash, like Obsidian.
  • LiveSync: certificate checks, a Sync tile in quick settings, sync on wake every 6 or 24 hours, conflicts kept as a copy and never overwritten. Not tried against a real Obsidian install yet.
  • Canvas files: pan, zoom, pictures in cards, tap a card to open its note. Excalidraw drawings open the same way, compressed ones too.
  • Import a vault from a ZIP over the device's web page. Pictures in your vaults show in the Gallery.
  • Three highlight styles, callouts in a frame, embeds of a heading or a block, frontmatter and tags.

Reading comfort

  • Every layout setting in the book's Text panel: font, size, line spacing 0 to 10, hyphenation (Greek too), Even Word Gaps, word and character spacing, margins down to 0, indent.
  • Advanced Typography: ligatures, kerning, widow and orphan control, headings kept with their text, hanging punctuation. Confirmed on a real X4 Pro.
  • Fourteen page backgrounds, from plain to papyrus and bath towel, with a contrast slider and a live preview.
  • Status bar options: choose what it shows, hide it, or show the page number counted from the start of the book (an estimate) in brackets, even with the bar hidden.
  • Tap Zones: turn pages from the whole page or only the corners.
  • Quick settings on a swipe down: light, warmth, night mode, refresh, sleep, Sync and the Library.

Tools in Home → Plugins

  • Sudoku: three levels, pencil notes, undo, hints, and it saves where you left off.
  • Dice: D&D and polyhedral dice, World of Darkness, Vampire V5 with Hunger dice and Rouse checks, Chronicles of Darkness, Fate, Powered by the Apocalypse, Blades in the Dark, Call of Cthulhu, Shadowrun, Savage Worlds, Year Zero and Cyberpunk Red. Not tried on a device yet.
  • Focus timer (Pomodoro) and Habits (daily habits with a streak and a total).
  • Flashlight: the front light as an S.O.S., blinking or steady.
  • VaultEUC connects over Bluetooth to Begode, Veteran, KingSong, InMotion, Ninebot and VESC wheels, with live numbers, alarms and ride logs. Not for use while riding, and not tried on a real wheel yet.
  • Plugins from the SD card and the Plugin Hub.

The device

  • A home screen with the book you're reading on top, then Books, Vaults, Favourites, Search, Files, Gallery, Transfer, Plugins and Settings, in any order, any of them hidden, and a home button in the top bar.
  • Settings grouped by task, with a search that finds a setting by name.
  • Browse Files with Move, Copy, Rename, Delete, New folder, Extract here and Info on every file, and a search of the whole card by name.
  • A Gallery for the pictures on the card, with filters and phone photos up to 50 MP; any picture can be the sleep picture.
  • A PIN or corner lock, with your name and phone on the lock and sleep screens.
  • A Battery page with the drain per hour asleep and awake.
  • Updates over Wi-Fi from the device itself, with the release notes first, What's New after an update, and a welcome guide on the first start.
  • No telemetry, no accounts, no payments. Free and open source (my code is MIT; the firmware binaries are GPL-3.0-or-later, see Licence).

Phone, Bluetooth and languages

  • Transfer & Remotes on the Home screen: file transfer over Wi-Fi, USB or Calibre, your WebDAV, FTP and SFTP servers and the SSH terminal, and a web page for files, notes, settings and LiveSync setup.
  • An Android companion app: quick notes, share books, comics, text and pictures from other apps, the SD card, the reader's settings, the comic converter inside the app, a Google Keep importer, typing into the reader from the phone, and the docs offline. Tested against the simulator, not a real X4 Pro yet.
  • A Bluetooth page turner, and a Bluetooth keyboard can type into the on-screen keyboard line (off by default, not yet tried with a real keyboard).
  • Interface in English and Greek, a Greek and English on-screen keyboard switched with the globe key, Greek hyphenation and fonts built in. Menus in many more languages from CrossPoint.

Scroll mode, SSH, and the first checks on a real X4 Pro

The first release where I could check part of the work on a real X4 Pro myself, over a USB developer link. Every item says which it is: checked on the device, or tried on a computer only. The screenshots are from the simulator.

Also checked on a real X4 Pro

  • Search no longer freezes. Opening Search blocked the reader for about 12 seconds on a vault of a few hundred notes. Now the keyboard appears in 0.8 s instead of 12.7 s, and a search of unchanged vaults is ready in about 2 s.

Tried on a computer only

  • SSH terminal and SFTP client (X4 Pro builds only): a shell on your own server on a line terminal, and SFTP in the same file browser as WebDAV and FTP. Tried against a real OpenSSH server from the computer, never from a device. There is no screenshot: the simulator is built without SSH.
  • DOC and CHM books: Word 97-2003 .doc files and .chm help files open as text.
  • Gamepad buttons (a scaffold): one Bluetooth gamepad’s buttons can be learned for the reader’s actions. It has never seen a real gamepad.
  • Auto warmth by the sun: the night window can run from sunset to sunrise for the latitude and longitude you type.
  • Gestures inside Reading presets: Save preset asks “Include gestures”.
  • Developer link, debug page and a developer build you can install: a read-only build answers status and log requests over USB, and the debug page makes a report file from it. It can’t read or write your files or settings, press keys or flash anything. It can reboot the reader, change the log level, take a screenshot and write a small bench log to the card. I used the full developer build for my own tests; the read-only build and the page haven’t been tried on a reader yet.
  • The X4 Pro firmware now also holds wolfSSH (GPL-3.0-or-later), so the firmware binaries are under GPL-3.0-or-later; VaultInk’s own code stays MIT.
  • Known bug: the bottom row of Settings (System) ignores a tap until you scroll the list.

Comics and manga

Comics, cut to fit the screen

Comics go through Banana Comic Converter, a free tool by u/curseofthebanana that runs in the browser on a phone or a computer. Instead of shrinking a whole page, it cuts every page into its panels and repacks them to fill the small screen. It has an X4 / X4 Pro preset, manga (right-to-left) or western order, a panel editor for the pages it gets wrong, and batch conversion.

How it works

Convert to XTCH (or XTC for the fastest page turns), upload the file with the companion app or the device's web page, and read it like a book. Plain CBZ files open too. On the reader, Settings → Library → Convert comics shows a QR code that opens the converter on your phone.

Android companion app

Your phone, talking to the reader

The companion app connects to the reader over Wi-Fi while File Transfer is open. Write a quick note or share text and pictures from any app straight into a vault, or books and comics straight to the reader; browse the whole SD card to upload, download, rename, move and delete; convert comics; and change the device settings from the phone.

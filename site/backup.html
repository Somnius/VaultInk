Xteink X4 Pro

Back up and restore

Copy everything stored in the reader's own memory (all 16 MB of flash: bootloader, firmware, settings) into one file on your computer, and write such a file back later. The SD card is not part of it.

Experimental: not tested on a real reader yet. The page's logic is tested on a computer with a simulated reader. Reading a backup, writing one back and the restart after it have not been tried on an X4 Pro. If you try it, please tell us what happened.

Nothing is uploaded. The page talks to the reader over USB, inside your browser. The backup is a file you save on your own computer. The browser downloads one program from a public server (jsDelivr) when you press Connect: esptool-js, Espressif's open-source flashing library.

Not supported in this browser. This page needs Web Serial. Use desktop Chrome, Edge or Opera on a computer. Firefox, Safari and browsers on phones and tablets are not supported.
This page must be opened over https (or from localhost). The browser does not allow USB access from other pages.

1. Connect

Use a USB-C data cable. Close other programs and tabs that use the port (a serial monitor, the install page, the debug page). Connecting restarts the reader into its download mode; if that fails, see step 4.

The page only works with an ESP32-S3 that has 16 MB of flash (the X4 Pro) and refuses anything else. While connected, the reader stays in download mode and its screen does not change. Restart the reader leaves that mode and disconnects.

2. Read the flash (backup)

Reads all 16 MB and takes several minutes. Make the backup before you install VaultInk if you want a way back to the stock firmware.

3. Write a backup back (restore)

This replaces everything on the reader, bootloader included. The firmware, the settings and everything else stored in the reader itself become what the file holds. The SD card is not touched. Use the cable that worked for the backup and a charged battery, and do not unplug while it writes.

The file is sent compressed, so the byte count is smaller than 16 MB. After the last byte the reader computes a checksum (MD5) of its flash and the page compares it with the file's. Then the page restarts the reader.

4. Download mode on the X4 Pro

The reader's chip has a small loader in its ROM that reads and writes the flash over USB. Connect asks the chip to restart into it over the USB cable (the USB-JTAG-Serial reset of esptool-js). We assume this works while VaultInk is running, and do not know whether it works from the stock firmware; it is not tested on a real reader yet. If Connect fails, put the reader into that mode by hand, the same way as for installing, then press Connect again:

  1. Put the X4 Pro into boot mode

    With the reader switched off, press and hold Power, then also press and hold both page-turn buttons, and keep holding them.

  2. Connect it to your computer

    Use a USB-C data cable (some cables only charge). Use Chrome, Edge or another browser with Web Serial, on a computer, not a phone.

  3. Press Connect on this page

    Choose the reader in the browser's list. When you are done, press Restart the reader; if the reader does not start, restart it with Power.

The reader is not in the list, or Connect fails

Try another cable (some only charge) or another USB port, and check the reader is still in boot mode. On Linux your user must be allowed to open the port (/dev/ttyACM0): the debug page lists the usual ways. Whether Windows needs a driver is not verified.

5. Privacy and safety

  • Nothing is uploaded. The backup goes from the reader to this tab and from there to a file on your computer. The page has no server to send it to.
  • Do not share a backup. It holds this reader's secret and its settings. Do not attach it to an issue or send it to anyone, us included.
  • A failed restore can be tried again. The loader this page talks to is in the chip's ROM and cannot be overwritten, so a reader whose restore stopped halfway should still enter download mode (step 4) and take the backup again over USB.
  • Do not unplug in the middle of a write. Use a cable you trust and a charged battery. An interrupted read does no harm: the flash is not changed by reading.
  • A backup from another reader carries that reader's settings and secret. The page warns when the MAC address in the file's name is not the connected reader's. Writing another reader's backup is not tested.
  • The page checks little about the file: its size, its first byte, and after writing that the flash holds the same bytes. It cannot tell whether the file is a working firmware. The SHA-256 is for you, to see that the file is still the one you saved.
